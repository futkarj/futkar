# Futkar

Site for **Futkar**, an advisory practice by Rohit Jain: change, in small pieces.

Built on AEM Edge Delivery Services from `adobe/aem-boilerplate`. Content is authored in Google Docs
(Drive folder `futkar-site`) and published with Sidekick. Rohit's portfolio lives at https://namerohit.com.

## Environments
- Preview: https://main--futkar--futkarj.aem.page/
- Live: https://main--futkar--futkarj.aem.live/

## Local development
1. `npm i`
2. `npx -y @adobe/aem-cli up` (opens http://localhost:3000)
3. `npm run lint`
